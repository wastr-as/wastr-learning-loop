# Meeting-transcript extractor — dependencies (issue #72, July priority #1)
#
# Python 3.10+ required (code uses X | Y unions).
#
# faster-whisper pulls in ctranslate2, the tokenizer, and PyAV (the `av`
# package). PyAV bundles the ffmpeg libraries, so audio/video decoding works
# out of the box — a separate ffmpeg install is NOT required. Install one only
# if you want the `ffmpeg` CLI for your own pre-processing:
#   * Windows:  winget install Gyan.FFmpeg   (or: choco install ffmpeg)
#   * macOS:    brew install ffmpeg
#   * Linux:    sudo apt install ffmpeg
#
# The Whisper model weights (~3 GB for large-v3) download on first run and are
# cached under ~/.cache/huggingface — no separate step needed.
